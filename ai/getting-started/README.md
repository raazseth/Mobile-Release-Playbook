# AI Integration Getting Started Handbook

This directory contains production handbook guides, onboarding workflows, quickstart tutorials, and setup instructions for **AI Integration** in the Mobile Release Playbook.

Engineered in alignment with **2026 platform specifications**, it details how developers integrate AI coding assistants into mobile release pipelines.

This guide is **not**:

- an authorization mechanism to skip reading subsystem documentation
- a substitute for configuring local IDE agent tools
- a guide to un-authenticated AI API calls
